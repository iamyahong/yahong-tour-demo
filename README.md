# yahong-tour-demo

Evibe 시연용 샘플 사이트입니다. 서울 일본어 관광 안내 사이트(Next.js, Vercel 배포)를 복제한 것으로, 실제 영업에 쓰이지 않습니다.

- `main` → 실서비스: https://yahong-tour-demo.vercel.app
- `staging` → 테스트 페이지: https://yahong-tour-demo-git-staging-iamyahong1.vercel.app

Evibe(https://evibe.replit.app)에서 문구 수정을 요청하면 `staging`에 반영되고, 테스트 페이지에서 확인 후 승인하면 `main`에 병합됩니다. `evibe:`로 시작하는 커밋이 그 기록입니다.

비밀값이나 고객 데이터는 포함되어 있지 않습니다.
